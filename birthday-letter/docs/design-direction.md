# 月光生日文具組

主題是一封可親手打開、拖曳翻面、尋找三份小幸福的生日信。依 2026-11-04 最新要求，信封、信紙正反面統一為柔霧粉紫與奶油白的日系文具。主角為原創小鴨、小狗與小貓。

## 設計計畫

| Token | 色彩 | 用途 |
| --- | --- | --- |
| 桌面 | `#EDE2F1` | 安靜的淡紫背景 |
| 淡紫 | `#DCCDF0` | 霧面信封、紙緣暈染 |
| 奶油白 | `#FFF9F2` | 中央閱讀區與紙張 |
| 乾燥玫瑰 | `#D8B2C1` | 小面積裝飾、第三份禮物 |
| 可可棕 | `#6E5651` | 正文與操作文字 |
| 灰紫 | `#CFC5D6` | 極淡方格、摺痕 |
| 月光黃 | `#F6E58B` | 小月亮與星星 |

字體沿用自託管 Noto Serif TC 標題與 Noto Sans TC 正文。標題 28–36px，正文 16–17px、行高 1.95，靠左閱讀。輔助文字使用可讀的深色，裝飾線才降低透明度。

## 對照與取捨

- 花枝與玫瑰封蠟最初改為抱月小鴨、一起探頭的小狗與淡紫小貓；2026-11-05 依使用者要求，信封小卡與信紙上的鴨子統一使用 `birthday-collection/happy-duck.png`，保留照片角色的大眼、愛心舌頭、平面腮紅及抬起的蹼足。
- 方格與紫色暈染是紙材細節。正面右上角放小鴨，狗貓與署名固定於下方，避免長信捲動時插圖壓住正文或紫色紙緣。
- 信封以扁平淡紫小花、柔綠細枝與尖葉構成不規則延伸的完整花框；原花束圖片已撤下。上緣花框在開信時隱藏，闔上後恢復，中央保留月亮星星封貼。
- 背面三個長方形按鈕由上至下等分剩餘空間，不需捲動，與紫色紙緣留白。圖示不顯示標題文字，拆封後換成開啟的餐罩／禮盒，保留無障礙名稱與依序解鎖。
- 信封的折線與開口保留層次，中心只留小月亮封貼與收件文字。
- 高解析透明插圖、CSS 紙材及 HTML 文字分開保存，方便日後重新編排印刷。這次交付為螢幕用 RGB 網站，尚非 CMYK／出血印刷完稿。插圖尺寸、來源與完整提示詞見 [artwork-provenance.md](artwork-provenance.md)。

## 互動與驗收

保留既有開信序列、真正 CSS 3D 正反面與桌面整張信紙空白處拖曳。手機左右滑動翻面、上下滑動閱讀；鍵盤使用左右方向鍵。標題與底部固定，僅中央內容捲動，隱藏捲軸。詳情仍以獨立 Portal 呈現，點擊畫面即可關閉，返回後保留清單位置與焦點。Reduced Motion 不影響功能。

收信圖示固定於頁面左上角，透過 Portal 放在信紙變形之外，觸控範圍至少 44px。手機頂部預留控制區，避免與信紙重疊。反向動畫沿開信路徑收回；信紙接近小卡時才交接，插入後才闔上封口。

實作後以桌面、手機與 WebKit 截圖檢查三種紙品、角落插圖及長文可讀性，並跑既有功能與拖曳回歸測試。正式信件與署名未提供，保留標示清楚的中性佔位內容。

## 四周紫色暈染調整

依最新參考，紙緣需要明顯的一整圈柔紫暈染。由原先上下兩團很淡的漸層，改成四邊連續、略有不規則水彩邊界的淡紫色帶；桌面寬約 35–60px，手機隨紙張比例縮小，中央仍為奶油白。色彩延續 `#DCCDF0`，邊緣增加灰紫 `#C6B0DA` 與少量 `#B9A2CD` 色素層次。保留目前字體、左對齊與角落小動物。

```text
┌ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ ┐
▒░                 ░▒
▒░    奶油白閱讀區   ░▒
▒░                 ░▒
└ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ ┘
```

對照參考後，使用可編輯 SVG 的柔化、不規則遮罩及細顆粒做紙材，避免形成規整的紫色框線。紙緣直接作為正反面共用背景，翻面與捲動時跟著整張紙，中央文字及禮物列不受遮蓋。
